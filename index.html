Estoque Almoxarifado

Projeto de TCC (SENAI) — Sistema de Controle de Estoque

📌 Sobre o projeto

Este projeto foi desenvolvido como Trabalho de Conclusão de Curso no curso de Análise e Desenvolvimento de Sistemas. O objetivo foi criar um sistema simples e funcional para controle de estoque e almoxarifado, focando na organização, cadastro e visualização dos dados.

🛠️ Tecnologias utilizadas

Python Django SQLite HTML CSS

👨‍💻 Desenvolvimento

O sistema foi desenvolvido em grupo, desde a modelagem até a implementação das funcionalidades. Participei ativamente da construção da lógica, estrutura do sistema e interface.
