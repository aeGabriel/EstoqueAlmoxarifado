📌 Sobre o Projeto

Este projeto foi desenvolvido como Trabalho de Conclusão de Curso (TCC), com o objetivo de criar um sistema para gerenciamento de estoque e almoxarifado, facilitando o controle de produtos, entradas e saídas.

🛠 Tecnologias Utilizadas

  • Python
  • Django
  • SQLite
  • HTML e CSS

👥 Trabalho em Grupo

Projeto desenvolvido em grupo para fins acadêmicos.
